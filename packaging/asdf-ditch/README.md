# asdf-ditch

asdf plugin that installs `ditch` from [GitHub Releases](https://github.com/baoulo/ditch/releases).

```bash
asdf plugin add ditch https://github.com/baoulo/asdf-ditch.git
asdf install ditch 0.2.0
asdf global ditch 0.2.0
ditch --version
```

Publish this directory to `baoulo/asdf-ditch` (or keep developing from the monorepo path).
